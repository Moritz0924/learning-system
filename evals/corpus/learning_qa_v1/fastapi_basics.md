# FastAPI 基础

## FastAPI 框架概述

FastAPI 是一个现代的、高性能的 Python Web 框架，用于构建 RESTful API。它基于 Starlette 和 Pydantic 构建，支持异步编程，并自动生成 OpenAPI 文档。FastAPI 的核心优势包括类型安全的请求/响应模型、自动数据验证、依赖注入系统和原生的异步支持。

## 路由与端点

FastAPI 通过路由装饰器（如 @app.get、@app.post）定义 API 端点。每个端点可以指定路径、HTTP 方法、请求体模型、查询参数和响应模型。FastAPI 会自动验证传入的请求是否符合定义的模型，如果验证失败则返回 422 错误和详细的错误信息。

## 依赖注入

FastAPI 的依赖注入系统允许开发者将公共逻辑（如数据库会话管理、身份认证、配置加载）抽象为可复用的依赖函数。通过 Depends 函数，端点可以声明其依赖项，FastAPI 会在处理请求前自动解析并注入这些依赖。依赖可以是嵌套的，支持复杂的依赖链。

依赖注入的一个常见用途是数据库会话管理。通过定义一个生成数据库会话的依赖函数，并在端点中声明依赖，可以确保每个请求使用独立的数据库会话，并在请求结束后自动关闭会话。

## 异步支持

FastAPI 原生支持 async/await 语法，使得处理 I/O 密集型操作（如数据库查询、HTTP 请求）时不会阻塞事件循环。端点函数可以声明为 async def，在函数内部使用 await 调用异步操作。对于 CPU 密集型操作，可以使用 run_in_executor 将其放到线程池中执行。

## Pydantic 模型验证

FastAPI 使用 Pydantic 模型进行请求和响应的数据验证。Pydantic 模型通过类型注解定义字段，支持复杂的数据类型、自定义验证器和嵌套模型。当请求数据不符合模型定义时，Pydantic 会抛出 ValidationError，FastAPI 将其转换为 422 响应。这种机制确保了 API 的类型安全性。
